# 3章 Leanにおける論理

## 3.1 命題論理

真偽が定まるような主張のことを命題という。
例えば、すべての自然数nに対してnは0以上である、は命題。

自然数nに対して、n+3=39が成り立つは命題ではない。これは述語と呼ばれる。

(述語については3.3でやるらしい)

### 3.1.1 命題

Leanでは命題全体の型がPropになる。(よくわからん)

### 3.1.2 仮定を使う

### 3.1.3 含意(->)

PならばQが成り立つ、はP->Qと表せる。
この->を含意という。

```
#eval False -> True
```

これがいまいちわからん。


introを利用すると、含意の前提条件を仮定として導入できる。

### 3.1.4 否定

否定は含意の特別なケース。
not Pは P->Falseとおなじ。

contradictionというタクティクがある。


exfalsoというタクティクを使えば、矛盾を示せば良いことが示せる。

### 3.1.5 同値性

### 3.1.6　論理積

### 3.1.7 論理和
